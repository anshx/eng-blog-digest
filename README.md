# Engineering Blog Digest

A daily-curated archive of interesting engineering blog posts. Each entry captures:

- **Problem** — what they were trying to solve
- **Approach** — how they solved it
- **Tradeoffs** — what they gave up
- **Why** — why this approach over alternatives

## Sources

- AI/LLM infra: Anthropic, OpenAI, Modal, LangChain, LlamaIndex, Pinecone
- Data/analytics infra: Databricks, Snowflake, ClickHouse, DuckDB, dbt, Redshift
- FAANG-tier eng: Netflix, Uber, Stripe, Cloudflare, Discord, Figma
- Hacker News top engineering posts

## Layout

```
digests/
  YYYY-MM-DD.md     # daily digest (one file per run)
posts/
  YYYY-MM-DD/
    <slug>.md       # individual post writeup
```

Updated daily at 6:00 AM IST by a scheduled Claude Code agent.
